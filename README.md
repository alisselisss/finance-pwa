# Мои финансы — личный финансовый PWA

Личное приложение для контроля повседневных расходов, свободных денег и накоплений.
Работает офлайн, все данные хранятся локально на устройстве (IndexedDB).

## Финансовая модель

- Зарплата приходит двумя выплатами: аванс (за 1–15 число) и зарплата (за 16–конец месяца).
  Суммы считаются из оклада после НДФЛ (по умолчанию 13%) пропорционально рабочим дням.
- Сразу после поступления часть денег откладывается на накопительный счёт.
- Остаток делится на календарные дни до следующей выплаты — это дневной лимит.
- Каждый вечер записывается сумма расходов за день:
  - меньше лимита — разница пополняет свободные деньги;
  - больше лимита — разница вычитается из свободных денег;
  - перерасход сверх лимита и свободных денег — предлагается уйти в минус
    или пересчитать дневной лимит на оставшиеся дни.
- Свободные деньги — главный показатель: сколько можно потратить сверх повседневного
  бюджета. Они не обнуляются при новой зарплате и не смешиваются с накоплениями.

## Запуск

```bash
npm install
npm run dev        # режим разработки: http://localhost:5173
```

## Проверки

```bash
npm test           # тесты финансовой логики (vitest)
npm run typecheck  # проверка типов TypeScript
npm run lint       # ESLint
npm run build      # production-сборка в dist/
npm run preview    # локальный запуск собранного приложения: http://localhost:4173
```

## Установка на телефон (PWA)

1. Соберите приложение: `npm run build`.
2. Раздайте `dist/` по HTTPS (например, `npx serve dist` на хостинге, GitHub Pages,
   Netlify и т.п.). Service worker требует HTTPS или localhost.
3. Откройте сайт на телефоне и добавьте на главный экран:
   - Android/Chrome: меню → «Установить приложение»;
   - iOS/Safari: «Поделиться» → «На экран “Домой”».
4. После первой загрузки приложение работает без интернета.

Для локальной проверки PWA на компьютере достаточно `npm run build && npm run preview`.

## Архитектура

```
src/
  domain/          # финансовая логика без React (тестируется отдельно)
    money.ts       # суммы в копейках (целые), форматирование ru-RU
    dates.ts       # календарные даты, високосные годы, будни
    salary.ts      # оклад, НДФЛ, аванс/зарплата по рабочим дням
    period.ts      # бюджетные периоды, следующая выплата
    engine.ts      # event-sourcing: события → производное состояние
    forecast.ts    # прогноз будущих выплат
    backup.ts      # экспорт/импорт резервной копии с валидацией
  storage/db.ts    # IndexedDB (single-key хранилище состояния)
  app/             # экраны: Onboarding, Home, Savings, Forecast, History, Settings
    useFinance.ts  # загрузка/сохранение состояния, производные показатели
    router.ts      # hash-навигация без библиотек
```

Финансовое состояние — журнал событий (`FinanceEvent[]`). Текущие балансы, свободные
деньги и лимиты всегда вычисляются из событий функцией `derive`, что делает расчёты
воспроизводимыми, а правку истории — безопасной.

## Резервные копии

Настройки → «Экспортировать резервную копию» скачивает JSON-файл со всеми данными.
Импорт проверяет формат и версию схемы и полностью заменяет состояние только после
явного подтверждения.
